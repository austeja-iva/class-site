CNT 3004

Computer Network Concepts

How networks work, from the physical layer up through TCP/IP, routing, and common protocols.

Homework 1: Networking Fundamentals & Infrastructure

What I learned

In this assignment, I learned about the OSI and TCP/IP models and network addressing. I also got hands-on practice using Terminal commands such as ping and traceroute.

Lab

This lab introduced me to Wireshark, its packet capture interface, and its three main panes.

Challenges

One challenge that I experienced with this assignment was deciphering the results of the ping commands. When I pinged one website I got 100% packet loss, and that was not the result that I was expecting.

Takeaways

Overall, with this assignment I was able to put networking concepts into practice and see how they work, through Terminal commands and Wireshark. I learned about the three main panes of Wireshark: packet list, packet details, and packet bytes.

Homework 2: Network Addressing, Protocols & Routing

What I learned

In this assignment, I learned about IP addressing, routing, TCP connections, and DNS. I also got more practice using Terminal commands to extract information such as addresses.

Lab

In the Wireshark lab portion, I captured HTTP traffic and learned how to apply display filters to narrow down specific information, such as specific packets. I also identified the TCP three-way handshake and looked at DNS queries and responses.

Challenges

One challenge during the lab was correctly identifying packets, because there were several connections.

Takeaways

Overall, this assignment helped me better understand how devices establish connections and communicate over a network, and let me practice analyzing packets during the hands-on portion.

Homework 3: Network Media and Wireless Networking

What I learned

This assignment taught me about different transmission media, bandwidth, throughput, and wireless communication.

Lab

In this lab, I utilized Wireshark to look at network traffic during a file download. I then compared bandwidth and throughput, and analyzed different types of wireless frames.

Challenges

One challenge was that there seemed to be a discrepancy in my recorded data, such as the Tx rate, which meant that my bandwidth may not have been accurately represented. This ultimately caused my throughput to be higher than my bandwidth, which is an unusual result. I also had some trouble applying Wireshark filters and then identifying the different wireless frames.

Takeaways

Overall, through this assignment, I was able to see how directly network performance is influenced by factors such as congestion, interference, and protocol overhead. And ultimately, I got better at using Wireshark for analysis.

Homework 4: Virtualization, Cloud Computing, Subnets, and VLANs

What I learned

In this assignment, I learned about virtualization (such as how to set up a virtual machine), cloud computing, subnets and how to calculate them, VLANs, and more about network configuration.

Lab

In the Wireshark lab portion, I practiced with HTTP GET requests and server responses by analyzing HTTP headers and seeing how browsers get web content.

Challenges

The trouble that I had with this lab portion was finding the correct HTTP requests and responses. I had to look at them carefully and use filters to narrow down information.

Takeaways

Overall, I got more comfortable using filters to narrow down information in Wireshark, and learned about and practiced with HTTP GET requests.

Homework 5 & 6: Network Security, Performance, Recovery, and WANs

What I learned

In this assignment, I learned about network security, performance, recovery, risk management, and network reliability.

Lab

During the lab, I got more practice analyzing TCP traffic, which I used to identify duplicate acknowledgments, retransmissions, and fast retransmissions. This taught me how to isolate individual TCP streams and calculate retransmission rates.

Challenges

The biggest challenge that I had during this lab was identifying the correct TCP stream for the file download. When I used filters, I sometimes got no matching packets, which made it hard to determine the number of retransmissions and duplicate acknowledgments. I also had trouble distinguishing between results from the entire capture and those from the specific download stream.

Takeaways

Overall, this assignment helped me understand how TCP continues to provide reliable communication despite packet loss. I also got more practice troubleshooting network performance issues using Wireshark.
